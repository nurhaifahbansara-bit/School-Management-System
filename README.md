# School Management System
*Academic Project | Completed during my 1st year 2nd sem*

This is a web-based application built using ASP.NET Core MVC. It is designed to help educational institutions manage their daily school operations and data more efficiently.

## Key Features
* **Student & Faculty Management:** Allows for organizing student records and teacher information.
* **Data Organization:** Uses the Model-View-Controller (MVC) architecture to keep the data logic separated from the user interface.
* **Modern Web Structure:** Features responsive web views and structured configurations for database management.

## Tech Stack Used
* **Backend Framework:** ASP.NET Core MVC, C#
* **Frontend:** HTML, CSS, Razor Views
* **Configuration:** JSON settings for environment and development setups
